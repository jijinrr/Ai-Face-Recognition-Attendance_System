# Ai-Face-Recognition-Attendance_System
An automated attendance management system using real-time face recognition powered by AI. This system captures facial data through a camera, recognizes registered users, and logs their attendance with timestamps. Ideal for schools, offices, and institutions seeking a secure, contactless, and efficient solution



🔍 Features

Real-time face detection and recognition using OpenCV and face_recognition
Attendance logging with accurate date and time stamps
MySQL database integration for persistent storage of users and attendance records
Tkinter-based GUI (tk.Frame) for easy user interaction
Admin functionality to register new users and view attendance history
⚙️ Tech Stack

Language: Python 3.x
Face Recognition: face_recognition, OpenCV
Database: MySQL
GUI: tkinter (tk.Frame-based layout)
📦 Use Cases

Schools and colleges
Offices and co-working spaces
Secure entry systems for buildings or labs
